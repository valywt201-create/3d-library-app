# مراجع تحقق نماذج Gemini

- تعرض صفحة نماذج Gemini API الرسمية `gemini-3.6-flash` ضمن نماذج Gemini Flash: https://ai.google.dev/gemini-api/docs/models
- تسرد صفحة إنهاء دعم Gemini API إصدارات النماذج ومواعيد الإيقاف المعلنة: https://ai.google.dev/gemini-api/docs/deprecations
- تدرج صفحة دورة حياة Google Cloud كلاً من `gemini-1.5-flash-001` و`gemini-1.5-flash-002` ضمن النماذج المتقاعدة في 2025: https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-versions
- توثق صفحة توليد المحتوى الرسمية صيغة REST لنقطة `generateContent` واستخدام `x-goog-api-key`: https://ai.google.dev/gemini-api/docs/generate-content
