# Architectural Decision Records (ADR)

## ADR-001: Core Tech Stack
- Status: Accepted
- Decision: Use React, Vite, TypeScript, and Tailwind CSS.
- Reason: Fast build times, strong type safety, and seamless 3D/UI integration.

## ADR-002: AI Developer Workflow
- Status: Accepted
- Decision: Use Roo Code extension with Google Gemini API (gemini-1.5-pro / gemini-1.5-flash).
- Reason: $0 budget requirement, zero message limits, and massive context window.
